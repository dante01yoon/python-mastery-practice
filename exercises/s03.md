# 연습문제 · 컬렉션

1. 좋아하는 음식 세 개로 리스트를 만들고, 첫 번째와 마지막 음식을 출력하세요.
2. `[3, 1, 4, 1, 5, 9, 2, 6]`에서 앞의 세 개와 뒤의 세 개를 슬라이싱으로 출력하세요.
3. 이름과 나이를 담은 딕셔너리를 만들고, 나이를 1 올린 뒤 출력하세요.
4. `["사과", "포도", "사과", "귤", "포도"]`에서 중복을 없앤 종류 수를 출력하세요. (힌트: 집합)
5. 딕셔너리에 없는 키를 `get`으로 꺼낼 때 기본값 "모름"이 나오게 하세요.

### 추가 수업 연습문제 (10/30)
6. 3×3 표 `[[1,2,3],[4,5,6],[7,8,9]]`에서 가운데 값과 오른쪽 아래 값을 출력하고, 둘째 줄의 합을 구하세요.
7. `a = [1, 2]`를 `b = a`와 `c = a.copy()`로 담은 뒤 `a`에 3을 붙이고, `b`와 `c`가 어떻게 되는지 출력해 이유를 주석으로 적으세요.
