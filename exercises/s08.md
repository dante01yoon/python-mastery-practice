# 연습문제 · 모듈·패키지·uv

1. `money.py` 모듈에 숫자를 받아 `"12,000원"`처럼 바꿔 주는 `won(n)` 함수를 만들고, 다른 파일에서 `from money import won`으로 불러 써 보세요.
2. 1번 `money.py` 아래에 `if __name__ == "__main__":` 블록을 넣어, 그 파일을 직접 실행할 때만 `won(12000)`이 출력되게 하세요.
3. `datetime`으로 오늘부터 30일 뒤 날짜를 `2026년 11월 28일` 모양으로 출력하세요.
4. 문장 하나에서 가장 많이 나온 글자 3개를 `Counter`로 구하세요(띄어쓰기는 빼고).
5. 카이사르 암호 패키지에 `brute_force(text)` 함수를 추가해, 1~25칸으로 모두 풀어 본 결과를 한 줄씩 출력하세요.

### 추가 수업 연습문제 (10/30)

7. 서울 시각 2026-11-03 09:00을 런던(Europe/London)과 도쿄(Asia/Tokyo) 시각으로 바꿔 출력하세요.
