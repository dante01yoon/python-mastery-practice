# 연습문제 · 함수

1. 숫자 하나를 받아 제곱을 돌려주는 함수 `square(n)`을 만들고 `square(7)`을 출력하세요.
2. 이름과 인사말을 받아 출력하는 `hello(name, word="안녕")`을 만들고, 인사말을 넣을 때와 뺄 때 두 번 불러 보세요.
3. 숫자를 몇 개든 받아 가장 큰 수를 돌려주는 `biggest(*nums)`를 만드세요. (힌트: max)
4. 리스트를 받아 짝수만 담은 새 리스트를 돌려주는 `evens(numbers: list) -> list`를 만들고 docstring을 붙이세요.
5. 재귀로 1부터 n까지의 합을 구하는 `total(n)`을 만드세요. (힌트: n이 0이면 0)
