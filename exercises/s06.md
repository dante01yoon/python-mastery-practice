# 연습문제 · 예외와 디버깅

1. `int("열")`을 실행해 보고, 오류 추적 맨 아래 줄에서 예외 이름과 설명을 적어 보세요.
2. 숫자 두 개를 입력받아 나눈 값을 출력하세요. 숫자가 아니면 「숫자로 적어 주세요」, 0으로 나누면 「0으로는 못 나눠요」를 출력하세요.
3. 리스트 `fruits = ["사과", "배", "귤"]`에서 입력받은 번호의 과일을 꺼내세요. 범위를 넘으면 `IndexError`를 잡아 「0~2 중에 골라 주세요」를 출력하세요.
4. 나이를 받아 0보다 작으면 `raise ValueError("나이는 0 이상")`를 일으키는 `check_age(age)`를 만들고, 부르는 쪽에서 잡아 메시지를 출력하세요.
5. 아래 함수는 리스트에서 가장 큰 수를 찾으려 하지만 틀린 값을 돌려줍니다. 디버거로 한 줄씩 따라가며 원인을 찾고 고치세요.

```python
def biggest(nums):
    best = 0
    for n in nums:
        if n < best:
            best = n
    return best


print(biggest([-5, -2, -9]))
```
