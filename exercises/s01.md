# 연습문제 · Git·GitHub 첫걸음

### 추가 수업 연습문제 (10/31)
1. 실습 저장소를 `git clone`으로 받고, `git log --oneline`에서 가장 최근 저장점 세 개의 메시지를 적어 보세요.
2. 새 폴더 `my-notes`에서 `git init`을 하고, `memo.txt`에 한 줄을 쓴 뒤 커밋하세요. 한 줄을 더 쓰고 한 번 더 커밋해서 `git log --oneline`에 두 줄이 나오게 하세요.
3. `memo.txt`를 고친 뒤 커밋하기 전에 `git diff`로 바뀐 줄을 확인하고, `git restore memo.txt`로 마지막 저장점 상태로 되돌려 보세요. (되돌린 내용은 다시 찾을 수 없으니 연습 파일에서만!)
